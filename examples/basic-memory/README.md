# Run an in-memory tree

This example gives you the smallest process-local ActiveFS tree: list two
entries, read a Markdown file, and run source-owned search without starting a
server.

## Run

From the repository root:

```bash
pnpm --filter @activefs/example-basic-memory build
node examples/basic-memory/dist/index.js
```

## Expected result

The command prints `/hello.md` and `/notes`, the `# Hello ActiveFS` document,
and:

```text
search matches: 1
```

The tree is mounted at `/` inside the example process.

## Paths

| Path | Result |
|---|---|
| `/hello.md` | Markdown generated by the in-memory declaration |
| `/notes/search.txt` | Text returned by the tree's source search |

## Limits

This fixture is read-only and process-local. It has no Source API server,
persistence, remote freshness state, cache, or OS mount.
