# Support

`0.1.1` is ActiveFS's first supported release. Version `0.1.0` and earlier have
no support commitment.

## Choose the right channel

- For reproducible bugs, documentation problems, and feature requests, use the
  [public issue tracker](https://github.com/ankitparasher/activefs/issues).
- For a suspected vulnerability, follow the private process in
  [Security](SECURITY.md). Never post vulnerability details publicly.
- For a sensitive conduct report, follow the private option in the
  [Code of Conduct](CODE_OF_CONDUCT.md).

## Include in a support issue

- the installed ActiveFS package and version;
- Node.js and operating-system versions;
- the exact command or API call that failed;
- sanitized logs and the smallest reproducible example; and
- the affected workflow, such as Source API, export, MCP, TUI, or mounted
  folder.

Do not include tokens, credentials, private source contents, or personal data.
ActiveFS support covers the generic packages and tools in this repository.
Product-specific sources and hosted deployments remain the responsibility of
their owners.

See [Troubleshooting](docs/troubleshooting.md),
[Supported environments](docs/reference/supported-environments.md), and
[Current limits](docs/reference/current-limits.md) before filing an issue.
