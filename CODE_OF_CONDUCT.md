# Code of Conduct

## Expected conduct

ActiveFS project spaces should remain professional, specific, and respectful.
Participants are expected to:

- focus criticism on code, behavior, documentation, and project decisions;
- provide enough context for others to understand or reproduce a concern;
- remember that public comments may be read by new contributors later; and
- avoid harassment, personal attacks, discriminatory language, threats, and
  sustained disruption.

Maintainers may edit, hide, lock, or remove content that makes the project
unsafe or harder to use. They may limit participation after repeated or severe
violations.

## Report a conduct concern

If the concern can be described safely in public, open a factual report in the
[issue tracker](https://github.com/ankitparasher/activefs/issues). Link the
relevant project interaction, describe the behavior, and state its impact.

For a sensitive report that should not be public, use the repository's
[private report form](https://github.com/ankitparasher/activefs/security/advisories/new)
and begin the title with `Conduct:`. This private form is a confidential intake
route for sensitive project reports; it is not a general support or maintainer
inbox. Do not include unrelated secrets or unnecessary personal information.

If you cannot use the private form, do not put the concern's details in a
public issue. Open an issue that asks only for a private reporting route; a
maintainer can arrange private contact before you share the report.

Report actual security vulnerabilities through the process in
[Security](SECURITY.md).

## Scope

This code applies to project-owned repositories, issues, pull requests,
documentation, examples, release channels, and other public ActiveFS project
spaces.

## Enforcement

Maintainers should respond consistently and proportionally. Responses may
include clarification, content edits, warnings, temporary moderation, or
removal from project spaces. Severe threats or illegal behavior may be
reported to the appropriate platform or authority.
